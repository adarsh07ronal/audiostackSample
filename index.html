Architecture

How it works

Three Python modules wired together to simulate a real automotive audio pipeline.

🔀

router.py

The AudioRouter cycles through music → nav → call modes on a frame counter, returning (wm, wn, wc) weights for each mode.

get_weights() → (wm, wn, wc)
🎚️

mixer.py

Converts PCM bytes to float32 arrays, applies per-stream weights, normalizes gain to prevent clipping, then converts back to PCM.

mix3(music, nav, call, wm, wn, wc)
🔊

hal.py

Hardware Abstraction Layer wraps PyAudio to open a 16-bit stereo output stream, isolating hardware details from the mixing logic.

Core mixing logic

Working in float32 prevents integer overflow during mixing, then clips back to int16 for PCM output.

# mixer.py — weighted mix of three PCM streams import numpy as np CHUNK = 1024 def mix3(music_bytes, nav_bytes, call_bytes, wm, wn, wc): m = np.frombuffer(music_bytes, dtype=np.int16).astype(np.float32) n = np.frombuffer(nav_bytes, dtype=np.int16).astype(np.float32) c = np.frombuffer(call_bytes, dtype=np.int16).astype(np.float32) L = min(len(m), len(n), len(c)) m, n, c = m[:L], n[:L], c[:L] mixed = wm * m + wn * n + wc * c # Normalize if total gain > 1 to prevent overflow total = wm + wn + wc if total > 1.0: mixed /= total # Clip to int16 range and convert back to PCM mixed = np.clip(mixed, -32768, 32767).astype(np.int16) return mixed.tobytes()
